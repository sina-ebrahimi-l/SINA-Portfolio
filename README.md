## Product Philosophy

Each product begins with a real operational problem.

The goal is not to add technology for its own sake, but to remove friction, connect fragmented workflows and create systems that remain practical in daily use.

## My Role

I lead product strategy, system architecture, trading-domain design, workflow development and operational decision-making.

The products are developed through collaboration with a small distributed team and an AI-assisted engineering workflow.

## Privacy

This repository is a public product showcase.

Production source code, customer information, credentials, private infrastructure and internal operational details are not included.

## Showcase Maintenance Rule

When a project change materially affects its public description, capabilities, architecture, integration boundaries or production status, the responsible developer must update the corresponding page in this repository in the same pull request or delivery.

A project change is not considered fully documented until its public showcase remains accurate. Sensitive implementation details, credentials, customer data and private repository links must never be added to the public showcase.
