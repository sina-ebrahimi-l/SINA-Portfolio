# SILO Collaborator Desk

**Status:** Production — 100%  
**Updated:** 2026-10-14

SILO Collaborator Desk is the authenticated front door for the internal content-production toolchain.

## What it does

- gives collaborators one consistent entry point
- shares authenticated access across supported production tools
- routes team members into SILO Visual Deck and SILO Publisher
- keeps admin navigation connected to Project Hub
- supports persistent light/dark presentation

## Product role

The Desk reduces friction around internal tooling by separating **access and navigation** from the specialized editing tools themselves. Visual work happens in Visual Deck; document production happens in Publisher; Collaborator Desk provides the common operational shell around them.

## Completion

The current scope is complete and in maintenance. New tools can be added later without changing the completed status of the existing access layer.
