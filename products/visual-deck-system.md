# SILO Visual Deck

**Status:** Production — 100%  
**Updated:** 2026-10-15

SILO Visual Deck is a recording-first HTML visual production system for educational and long-form video.

## What it does

- turns narration or structured text into editable visual scenes
- supports project-based scene and document management
- allows projects and HTML documents to be renamed directly from the Deck dashboard
- allows Blank projects and Blank HTML documents
- provides generated starter compositions for faster ideation
- supports scene ordering and section/beat-based staged reveals
- provides draggable and resizable elements
- supports typography, shapes, color controls, masks and crop positioning
- supports motion in/out and restrained idle motion
- supports media assets and presenter-controlled progression
- includes a server-backed Sound Effects library
- allows Sound Effects to be assigned per slide or per section/beat
- uses sound-led transitions: on click the sound starts immediately and the visual change begins at the midpoint of the sound, bridging the previous and next visual states
- exports portable standalone HTML with assigned audio embedded
- uses shared collaborator authentication and ownership-aware project access

## Product approach

The goal is not to replace video-editing software. The system moves repeatable visual decisions **before recording**, so fewer graphics need to be reconstructed later in post-production.

Sound is treated as part of the presentation timing rather than as a detached playback layer: presenter clicks can use an assigned effect as a transition bridge, with the visual change synchronized to the center of the audio event.

## Completion

The current production scope is complete at 100%. Further changes are new templates, layout patterns, integrations or UX refinements rather than unfinished core work.
