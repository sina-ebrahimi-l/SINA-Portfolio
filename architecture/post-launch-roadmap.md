# Post-Launch Roadmap

## Trading Directory

**Status:** Deferred — start only after the main website is complete and stable.

### Goal
Build a trading-focused directory inside the main website as a long-term acquisition, SEO and lead-generation layer rather than as a simple link list.

### Initial concept
Create a structured `/directory/` section on the main domain with dedicated landing pages for resources used by traders.

Potential categories:
- Brokers
- Trading tools
- Trading journals
- Market/data resources
- Educational resources
- Trading concepts / glossary
- Market-specific resource pages

### Product direction
Each directory item should be a useful landing page, not only a listing. Pages can include structured information, comparisons, FAQs, official-source links, related SINA content and relevant next steps into the wider ecosystem.

Example routes:
- `/directory/brokers/opofinance`
- `/directory/tools/tradingview`
- `/compare/opofinance-vs-exness`
- `/best/gold-trading-brokers`
- `/best/trading-journals`

### Business role
The directory should sit near the top of the funnel:

Search / discovery → directory page → useful tool, comparison or content → free resource / community → School, Academy or Mentorship

### MVP idea
After the website is finished:
- 5 core categories
- ~30 high-quality listings
- Search and filters
- Comparison pages
- High-intent “best” pages
- Internal linking to existing SINA content and products

### Naming direction
Working names:
- SINA Trading Directory
- SINA Trading Index

### Constraint
Do **not** move this into the current website-development scope. Revisit only after the main site launch and stabilization.
